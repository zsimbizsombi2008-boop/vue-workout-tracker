
# Vue Workout Tracker

A workout tracker built with Vue 3 and Vite as a learning project.

## Features

- Add new workouts
- Edit and delete workouts
- Search workouts
- Calculate total workout time
- Mark workouts as completed
- Save workouts in localStorage
- Reusable modal component with slots
- Keyboard handling and automatic input focus

## Tech stack

- Vue 3
- Vite
- JavaScript
- HTML
- CSS
- Composition API

## Run locally

```bash
npm install
npm run dev
